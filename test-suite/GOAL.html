ADC Test Suite
Overview Features Wireframes Current State Roadmap Storage
Priority #1

Record. Run. Ship with confidence.

A Playwright-based test recording and execution system built into ADC. Record browser interactions, save reusable tests, capture screenshots, and export as GitHub Actions CI workflows.

Core Features

What we're building

Five capabilities that make up the full Test Suite feature.

◉

1. BrowserView Recorder

Embed any URL in a fixed-dimension BrowserView. Record clicks, inputs, navigations, and keyboard actions as Playwright steps in real time.

  • Fixed pixel width/height for deterministic coordinates
  • Selector priority: data-testid > ARIA > label > text > CSS > coordinates
  • Chrome DevTools MCP selectors when available
  • Works with localhost, preview URLs, and staging
MVP
📂

2. Team-Wide Test Storage

Tests save to test-suite/ in the project repo. Shared config, auto-generated README, and gitignored screenshot output.

  • Each recording = standalone .spec.ts
  • Shared playwright.config.ts generated on first save
  • Auto-generated README.md with test inventory
  • Committed to repo for team-wide access
MVP
📷

3. Screenshot Capture

Configurable screenshot triggers: per-click, per-navigation, per-form, per-assertion, manual, or smart mode (default).

  • Saved per test run with timestamps
  • Temp folder mode for PR/ticket attachments
  • In-app screenshot viewer with share/export
  • Future: attach to PR, Jira, Slack
MVP (capture) + Next (sharing)
🌐

4. Any URL Support

Test against localhost, Vercel preview URLs, staging environments, or any HTTPS site. Auth fixtures handle login flows.

  • Self-signed cert bypass for HTTPS localhost
  • Auth fixture records login separately
  • No restrictions on target URL
MVP
⚙

5. GitHub CI Export

Export recorded tests as GitHub Actions workflows. Generates .github/workflows/test-suite.yml with Playwright setup, artifact upload.

  • One-click export from in-app
  • Additive: new tests add to existing workflow
  • Artifact upload for screenshots + reports
  • Runs on PR against src/** and test-suite/**
MVP
⚙

6. Settings & Configuration

Persistent QA recorder config in Settings. Default URL, BrowserView dimensions, screenshot mode, preload path. Auto-loads last-used config.

  • Stored in settings_kv (existing infra)
  • Multiple saved configs (selectable)
  • Auto-loads on app start
  • Per-project overrides
MVP

Feature Breakdown

Deliverables by phase

Feature Phase Description Depends On
Setup/Onboarding Flow MVP When no config exists, show a setup card instead of an error. Captures URL, dimensions, screenshot mode. Saves to settings_kv. Settings integration
Settings Tab (Testing) MVP New "Testing" tab in Settings page. Default URL, BrowserView dimensions, screenshot mode, saved configurations with active/switch/edit/delete. —
Layout Redesign MVP 3-panel layout: step panel (left), BrowserView (right), output (bottom). URL bar in toolbar. Recording indicator. Setup flow
BrowserView (fixed dims) MVP Replace webview tag with Electron BrowserView at user-specified pixel dimensions. Nav controls (back/forward/reload). Dimension label. Settings
Recorder Preload (enhanced) MVP Capture clicks, fills, selects, keyboard, navigation. Selector priority with Chrome MCP fallback. Coordinate capture at fixed dimensions. BrowserView
Test Storage (test-suite/) MVP Save recordings as .spec.ts in project's test-suite/scripts/. Auto-generate playwright.config.ts and README.md. Recorder
Test Runner MVP Run saved tests via Playwright CLI (child_process.spawn). Stream output to UI. Show pass/fail per step with timing. Test storage
Screenshot Capture MVP Configurable triggers (smart/per-click/per-nav/manual). Save to test-suite/screenshots/ or temp dir. Named by step. Test runner
Screenshot Viewer Next In-app viewer: thumbnail strip + large preview. Copy to clipboard, export as ZIP. Browse by test run. Screenshot capture
GitHub CI Export Next Generate .github/workflows/test-suite.yml. Additive (doesn't replace existing). Preview YAML before commit. Test storage
Screenshot Sharing Future Attach screenshots to PR descriptions, Jira tickets, Slack posts. Share button in viewer with destination picker. Screenshot viewer
Auth Fixtures Future Record login flow separately as reusable fixture. Auto-replay before test execution for authenticated sites. Recorder
Storage System

Test file structure

Tests are stored in the project repo at test-suite/. Team-wide, version-controlled, CI-ready.

test-suite/
  playwright.config.ts # auto-generated shared config
  README.md # auto-generated test inventory
  scripts/
    login-flow.spec.ts
    task-crud.spec.ts
    dashboard-widgets.spec.ts
  screenshots/ # gitignored
    login-flow/
      2026-04-10T154200/
        01-navigate-login.png
        02-fill-email.png
        05-assert-dashboard.png
  fixtures/
    auth.ts # reusable login flow
    helpers.ts # shared utilities
Storage Rules

Version controlled

Spec files and config committed to repo. All team members get the same tests on pull.

Screenshots gitignored

Output is ephemeral per run. Temp folder mode available for PR/ticket use.

Auto-documented

README.md regenerated on every save with test names, descriptions, and last-run status.

CI-ready

Spec files run directly with npx playwright test test-suite/scripts/. No ADC dependency.
